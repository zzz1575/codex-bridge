# Codex App Server WebUI v0.3.13

Settings now opens in its own panel, so changing a preference no longer replaces the session list. On desktop, a category sidebar separates General, Account, Usage, and Connection & diagnostics. On mobile, Settings opens full screen with a category list and a back button for each detail page.

Closing Settings returns to the previous conversation or session list. The panel keeps each category's scroll position as you move between them, and supports Escape and keyboard focus navigation on desktop.

Passkey entries also fit narrow widths: the device name uses the available space while Remove stays on one line.
