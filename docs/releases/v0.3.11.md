# Codex App Server WebUI v0.3.11

- Start a session directly from a project, fork a completed turn into the current directory or a
  new Git worktree, or open a temporary conversation from a turn or selected text.
- Temporary conversations have their own composer, a copyable session ID, and a tool step count.
- Edit and rerun the latest interrupted prompt when it has no Steer input. Queue and Steer controls
  keep pending messages visible while delivery is in progress.
- Paste images, upload files of any format with progress, and browse computer-use screenshots in
  the conversation. The sign-in page supports password-manager autofill on mobile browsers.
- Read command output in a terminal-style panel and see token usage for the past 7 and 30 days in
  Settings. The CLI can register projects and create sessions.

See the [installation guide](../install.md) and [release history](./).
